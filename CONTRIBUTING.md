# Как помочь проекту

Автор: **ddedlish** — [Steam](https://steamcommunity.com/id/ddedlish/)

1. **Новая модель** — проще всего: одна строка в `src/Glance.Core/Profiles.cs`,
   например `new(@"Tour\s?Pro\s?3", DeviceKind.Earbuds, true)`.
2. **Ошибка** — issue по шаблону, приложите `glance.log`.
3. **Код** — проект закрытый; предложения по коду присылайте автору в issue.

Принципы: никакого опроса в простое, никакой рекламы и телеметрии, интерфейс — в стиле Windows 11.
