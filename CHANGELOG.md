# Изменения

## 2.0.1
- Кнопка «Параметры Bluetooth» в панели больше не обрезается
- Описания в настройках переносятся на вторую строку вместо обрезки

## 2.0.0
- Единый файл-установщик для Windows x64/x86 с выбором диска; Linux x64/ARM64 с установкой без root
- Иконка-батарея, которая разряжается (батарея / проценты / батарея + %)
- Баннер критического заряда поверх игр без перехвата фокуса
- ~90 брендов в базе моделей; заряд DualSense / DualShock 4
- Автор: ddedlish

## 1.0.0
- Первая версия: значки в трее, окно подключения, заряд каждого наушника (AirPods, Fast Pair)
