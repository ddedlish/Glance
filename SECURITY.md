# Безопасность

Нашли уязвимость? Пожалуйста, не публикуйте детали в открытых issue —
используйте **Security → Report a vulnerability** в этом репозитории
или напишите автору: [ddedlish в Steam](https://steamcommunity.com/id/ddedlish/).

Поддерживается последняя версия из [Releases](../../releases).

## Как устроена защита
- Обновления: только HTTPS с github.com, проверка SHA-256 по `SHA256SUMS` до замены файла.
- Установщик: только HKCU, без рекурсивного удаления, проверка пути, права администратора — только для копирования в выбранную папку.
- Системные DLL загружаются только из System32 (защита от подмены DLL в «Загрузках»).
- Без телеметрии; сеть используется только для проверки обновлений.
