# Glance — заряд аксессуаров в трее

**Автор: [ddedlish](https://steamcommunity.com/id/ddedlish/)** · Windows 10/11 · Linux · Glance Pro

Glance показывает заряд Bluetooth- и беспроводных аксессуаров в трее рядом с часами: каждому устройству — свой значок-батарейка, которая разряжается вместе с ним. Работает на **Windows 10/11 x64 и x86** и **Linux x64 и ARM64**.

**Один файл — это и установщик, и программа.** Ставить .NET или что-то ещё не нужно: среда выполнения уже внутри.

| Файл из релиза | Для чего |
|---|---|
| `Glance-win-x64.exe` | Windows 10/11, 64-бит (почти все ПК) |
| `Glance-win-x86.exe` | Windows 10, 32-бит |
| `Glance-linux-x64` | Linux, обычные ПК |
| `Glance-linux-arm64` | Linux на ARM (Raspberry Pi 4/5, ARM-ноутбуки) |
| `SHA256SUMS` | Контрольные суммы всех файлов |

## Возможности

* **Значок-батарея**, которая разряжается вместе с устройством. Вид выбирается в настройках: батарея, проценты или батарея с цифрами внутри. Цвет меняется при низком заряде, на зарядке появляется молния.
* **Около 90 брендов в базе моделей**: наушники, гарнитуры, колонки, мыши, клавиатуры, геймпады, стилусы, часы. По имени устройства Glance определяет тип и вид окна: для TWS-наушников — кольца левого, правого и кейса; для накладных и шейных наушников, колонок, мышей, клавиатур, геймпадов — своя раскладка.
  *Apple, Beats, JBL, Harman Kardon, AKG, Samsung, Google, Nothing/CMF, Huawei, Honor, Xiaomi/Redmi/POCO, OnePlus, OPPO, realme, vivo, Motorola, Sony, Soundcore, Marshall, Bose, Sennheiser, Jabra, Poly, Audio-Technica, Shure, B&O, B&W, beyerdynamic, Technics, Panasonic, Philips, Skullcandy, Urbanears, Marley, Ultimate Ears, Tribit, Edifier, 1MORE, QCY, Haylou, SoundPEATS, EarFun, TOZO, Baseus, UGREEN, Lenovo, Яндекс, Sber, VK, SteelSeries, HyperX, Corsair, Turtle Beach, ASUS ROG, Logitech, Microsoft/Xbox, Razer, Keychron, NuPhy, Lofree, Rapoo, A4Tech, HP, Dell, Satechi, Glorious, Pulsar, Zowie, Wacom, XP-Pen, Huion, Nintendo, 8BitDo, GameSir, Flydigi, PowerA, Backbone, Valve, NVIDIA, Amazon, Thrustmaster, HORI, iPega, Garmin, Amazfit, Fitbit, Polar, Shokz.*
* **Заряд каждого наушника**: AirPods и Beats через рассылку Apple; JBL, Sony, Pixel Buds, Nothing, Xiaomi и другие — через Google Fast Pair.
* **Геймпады**: Xbox; DualSense, DualSense Edge и DualShock 4 — заряд читается прямо из контроллера (Windows его не показывает); остальные — если заряд сообщает Windows.
* **Критический заряд поверх игр.** Небольшой баннер сверху экрана поверх игр, видео и презентаций. Он не сворачивает игру, не забирает фокус и пропускает клики сквозь себя, а через несколько секунд исчезает сам. Показывается на пороге (по умолчанию 10%) и затем при каждом падении ещё на 5%.
* **Окно при подключении**, карточка при наведении на значок, прогноз «хватит примерно на 3 ч 20 мин», график заряда за сутки.
* **Уведомления без спама**: о низком заряде и о полной зарядке — по одному разу за цикл. Обычные окна молчат в играх и в режиме «Не беспокоить».
* **Ctrl + Alt + B** открывает панель; переименование устройств; скрытие отдельных устройств из трея.
* **Обновления** через GitHub Releases с проверкой SHA-256.

## Установка

### Windows
1. Запустите `Glance-win-x64.exe` (или `-x86`).
2. Откроется простое окно: папка установки (по умолчанию `%LOCALAPPDATA%\Programs\Glance`, без прав администратора), переключатель «Запускать вместе с Windows» и кнопка **«Установить»**. Другой диск или папку можно выбрать по ссылке «Изменить папку…».
3. После установки Glance сразу запускается. Удалить можно через «Параметры → Приложения».
4. Windows 11 прячет новые значки: нажмите стрелку ˄ в трее или включите значок в *Параметры → Персонализация → Панель задач → Другие значки*.
5. Портативный режим без установки: запустите с ключом `--portable` или положите рядом с exe пустой файл `portable.txt`.

> Файл пока без цифровой подписи, поэтому SmartScreen может предупредить: «Подробнее → Выполнить в любом случае». Чтобы предупреждения не было, подпишите файл сертификатом подписи кода (см. «Безопасность»).

### Linux
```bash
chmod +x Glance-linux-x64 && ./Glance-linux-x64
```
* В терминале появится выбор: домашняя папка (рекомендуется, без root) или любой подключённый диск. Если запустить файл двойным щелчком, вопросы задаст диалог `zenity` или `kdialog`.
* Установщик добавит пункт в меню приложений, иконку, автозапуск и команду `glance`.
* Удаление: `glance --uninstall`, вместе с настройками — `glance --uninstall --purge`.
* Трей работает в KDE, XFCE, Cinnamon, MATE, LXQt и Budgie. В **GNOME** нужно расширение *AppIndicator and KStatusNotifierItem Support* (в Ubuntu оно уже установлено). Уведомления работают везде.
* Источник данных — UPower: Bluetooth-гарнитуры, приёмники Logitech Unifying и Bolt, DualSense и DualShock, Xbox-геймпады (xpadneo), Nintendo, мыши и клавиатуры Apple Magic. Работает только по событиям, без опроса.

## Нагрузка на систему

* **Windows:** подключения приходят событиями от Windows, процессор не тратится. Заряд у Windows запрашивается раз в минуту и только когда что-то подключено (около 1–3 мс). BLE-сканирование идёт около 8 секунд в минуту и только при подключённых наушниках. Анимации работают только пока видны. Значки перерисовываются только при изменении.
* **Linux:** только события D-Bus, никаких таймеров опроса.
* **Память:** сборщик мусора настроен на экономию, после закрытия окон рабочий набор памяти уменьшается.

## Ограничения — честно

* **Эксклюзивный полноэкранный режим** (старые игры на DirectX 9/11 в «настоящем» fullscreen): поверх такой игры не может нарисовать ни одна программа без внедрения в игру. Glance в игры не внедряется — это небезопасно и может привести к бану античитом. Баннер покажется после Alt+Tab. В оконном и безрамочном режимах, а также в современных DX12- и Vulkan-играх с оптимизацией полноэкранного режима баннер виден.
* **Заряд каждого наушника** приходит только от моделей, которые его транслируют. Samsung Galaxy Buds используют закрытый протокол — для них показывается общий заряд. На Linux раздельный заряд наушников пока не поддерживается.
* **Беспроводные гарнитуры с собственным 2.4 ГГц-донглом** (Arctis, Corsair, Logitech G и другие): у каждой свой закрытый протокол. На Linux многие из них видны через UPower, на Windows — только если заряд сообщает сама Windows.
* **DualSense и DualShock по Bluetooth** сообщают заряд, только когда контроллер переключён в «полный» режим. Его включает любая игра или Steam. По USB заряд виден всегда.

## Безопасность

Что проверено при аудите:
* **Обновления:** загрузка только по HTTPS и только с github.com или *.githubusercontent.com, ограничение размера, проверка SHA-256 по `SHA256SUMS` (сравнение без утечки по времени). Файл заменяется только после успешной проверки; при неудаче откатывается.
* **Подмена DLL:** установщик обычно запускается из «Загрузок», поэтому системные библиотеки загружаются только из System32 (`SetDefaultDllDirectories` и `DefaultDllImportSearchPaths`).
* **Установщик:** проверяет путь — запрещены папка Windows, сетевые пути и символы, опасные для командной строки. Удаляет только созданные им файлы, рекурсивного удаления нет. Повышенные права используются только для копирования файла в выбранную папку. В реестр пишется только в HKCU.
* **Linux:** без root и без вызова оболочки. Строка запуска в `.desktop` экранирована по спецификации. Прежняя копия останавливается мягко (SIGTERM) после проверки имени процесса.
* **Разбор BLE- и HID-пакетов:** проверка границ на каждом шаге. Контроллеры открываются только на чтение и в общем режиме — игры и Steam продолжают работать.
* **Сеть** используется только для проверки обновлений; её можно выключить. Телеметрии нет.

Рекомендация: подпишите сборки сертификатом подписи кода — это уберёт предупреждение SmartScreen и защитит от подмены файла в репозитории.

## Сборка

```bash
./build.sh          # Linux/macOS: все сборки в dist/
build.bat           # Windows: x64 и x86 в dist\
```
Нужен .NET 8 SDK. Каждый push в GitHub собирает все 4 файла и `SHA256SUMS`, а тег `v*` публикует релиз.

## Публикация на GitHub

1. Создайте пустой репозиторий (например, `Glance`) и загрузите проект:
   ```bash
   git init && git add . && git commit -m "Glance 2.0"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/Glance.git
   git push -u origin main
   ```
2. Вкладка **Actions** соберёт все 4 файла (артефакт `Glance-all`).
3. Релиз создаётся сам: каждый push в `main` публикует (или обновляет) релиз `v<Version>`. Для новой версии увеличьте `<Version>` в `src/Glance/Glance.csproj`.
4. Автообновления настраиваются сами: при сборке в GitHub в программу вшивается адрес именно вашего репозитория (`github.repository`). Править код не нужно.
5. Рекомендуется: *Settings → Code security* → включить **Private vulnerability reporting** и **Dependabot alerts**.

В репозитории уже есть шаблоны issue (ошибка, новое устройство, идея), шаблон pull request, `SECURITY.md`, `CONTRIBUTING.md`, `CHANGELOG.md` и Dependabot.

## Устройство кода

```
src/
├─ Glance.Core/      общее: модель, база моделей (Profiles.cs), история и прогноз, настройки,
│                    парсеры AirPods/Fast Pair, сопоставление наушников, обновления
├─ Glance/           Windows: трей (Shell_NotifyIcon + GUID), окна, баннер критического заряда,
│                    Bluetooth (WinRT, SetupAPI, GATT, BLE), DualSense/DS4 по HID, встроенный установщик
└─ Glance.Linux/     Linux: UPower, трей StatusNotifierItem + dbusmenu, уведомления,
                     собственный растеризатор иконок, установщик
```

**Как добавить модель:** допишите правило в `Glance.Core/Profiles.cs`, например
`new(@"Tour\s?Pro\s?3", DeviceKind.Earbuds, true)`.

**Данные:** `%LOCALAPPDATA%\Glance\` на Windows, `~/.local/share/glance/` на Linux.
